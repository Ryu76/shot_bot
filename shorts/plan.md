# 나스닥 50종목 데일리 쇼츠 제작 계획

## 목적

한국시간 기준 전날 발생한 나스닥 연관 이슈를 한 영상에 하나의 인과관계만 담아 60초 안에 설명한다. 50종목을 모두 읽지 않고 히트맵으로 보여주며, 실제 단타 봇의 다음 리밸런싱에서 확인할 종목과 반증 조건을 제시한다.

## 체류시간 구조

| 구간 | 역할 | 화면 |
|---|---|---|
| 0.0~1.5초 | 결론·위기형 훅 | 사건명 + 투자자 영향 |
| 1.5~4초 | 증거 플래시·오픈루프 | 실제 수치/공식 출처 + 미공개 보상 |
| 4~10초 | 최소 맥락 | 누가, 언제, 무엇을 발표했는지 |
| 10~18초 | 한 줄 인과관계 | 사건 → 핵심 변수 → 종목 영향 |
| 18~27초 | 통념 반전 | “하지만” 패턴 인터럽트 |
| 27~37초 | 영향 우선순위 | 직접 / 조건부 / 역풍 |
| 37~49초 | 50종목 매핑 | 5×10 히트맵 + 대표 3종목 |
| 49~55초 | 반증 조건 | 이 판단이 달라질 조건 |
| 55~60초 | 루프·CTA | 첫 훅을 다시 닫고 행동 하나만 요청 |

## 디자인

- 1080×1920, 30fps, H.264/AAC MP4
- 어두운 네이비 배경, 상승 초록, 경고 주황, 하락 빨강
- 자막 최대 2줄, 핵심 단어 1개만 강조
- 화면 변화 1.5~6초, 18초와 37초에 큰 패턴 인터럽트
- 금융 정보 면책과 데이터 기준일을 모든 영상에 표시

## 콘텐츠 원칙

1. 사실과 해석을 분리한다.
2. 종가가 확인되지 않은 장중 수치는 “장중”으로 명시한다.
3. 직접 관련과 간접 관련을 구분한다.
4. 특정 종목의 매수·매도를 권유하지 않는다.
5. 50종목 중 이슈와 관련 없는 종목은 중립으로 표시한다.
6. 리밸런싱 후보는 뉴스만으로 결정하지 않고 기존 점수·유동성·RSI 조건과 함께 본다.
