# shot_bot 변경 기록 — 2026-07-14 / 001

## 한국투자 해외주식 API 모듈

- `hantoo_api/client.py`를 추가했다.
- `hantoo_api` Excel 명세의 REST API 47개를 `HantooClient` 메서드로 구성했다.
- 실시간 시세 4종은 WebSocket 구독 메시지 생성 함수로 제공한다.
- 공통 인증 헤더, GET 쿼리 파라미터, POST JSON 본문, API 오류 처리를 구현했다.
- `HantooClient.paper`로 모의투자/실전투자 환경을 구분한다.

## 단타 매매 및 리밸런싱

- 기존 `alerts.py`의 가격 알림 중심 구조를 매매 액션 중심 구조로 확장했다.
- `evaluate_trade_actions()`는 선정 종목 최대 50개와 실보유수량을 비교하여 다음 액션을 만든다.
  - 신규 진입 및 목표수량 증액: `buy`
  - 손절가 도달: `sell` (`stop_loss`)
  - 선정 종목 탈락: `sell` (`rebalance_exit`)
  - 목표수량 축소: `sell` (`rebalance_reduce`)
- 동일 조건에서 주문이 중복 생성되지 않도록 상태값을 유지한다. 주문 체결 후 최신 잔고를 다시 넣으면 해당 상태는 해제된다.
- `execute_trade_actions()`는 한국투자 해외주식 주문 API의 제한가 주문 payload를 만든다.
- 기본값은 `dry_run=True`이며, 실계좌 주문 전송은 `dry_run=False` 및 `confirm_live=True`를 동시에 지정해야 한다.

## 개인정보 및 인증 정보 관리

- 한국투자 앱키, 앱 시크릿, 접근 토큰, 계좌번호, 계좌상품코드는 `.env`에서 관리하도록 변경했다.
- `.env.example`에는 필요한 변수명만 제공하며 실제 인증값은 포함하지 않는다.
- `.gitignore`에서 `.env` 및 변형 파일을 제외한다.
- `HantooClient.from_env()`로 인증 정보를 로드하고, `execute_trade_actions()`는 계좌 정보를 생략하면 `.env`에서 읽는다.

## 검증

- Python 컴파일 검증을 완료했다.
- 네트워크 호출 없이 GET/POST 요청 조립, 모의투자 TR ID 선택, 매수·매도·손절·리밸런싱 및 중복 방지 로직을 검증했다.
- `.env`에서 클라이언트 인증값과 주문 계좌 정보를 로드하고, 모의투자 주문 payload를 만드는 것을 검증했다.
